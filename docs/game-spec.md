# 深淵の胎動（仮） ゲーム仕様書

現行仕様は v0.3.1 時点。開発方針には今後の改修内容を記載する。第壱話のエンディング名を含む。

## ゲーム概要（ユーザー向け）

**この世のあらゆる恐怖と不快感を詰め込んだ、狂気の探索型ミステリー。**

スマホ横画面を想定した、クトゥルフ風の分岐型ホラーノベル。第壱話「廃療養所の地下室」では、行方不明の妹を追って山奥の廃療養所を探索する。第弐話「黒潮の灯台守」は予告のみ。

## 画面と操作

- 起動時に更新内容を表示。閉じると警告画面になり、開始をタップするとタイトルへ進む。
- タイトルから新規開始、続きから、設定を選ぶ。
- 本文の表示中にタップすると文を一括表示し、表示後のタップで次の文に進む。分岐は表示された選択肢を押す。
- プレイ画面から地図、所持品、保存、設定、全画面切替を開く。全画面と横向きロックはブラウザが対応する範囲で動作する。

## 探索と分岐

玄関ホールから暗い廊下に進み、旧診察室の探索を経由するか、そのまま地下階段と深淵の間へ進む。旧診察室で錆びた鍵と油缶を拾える。地図は現在地と訪問済みの部屋を表示する。

| 要素 | 仕様 |
|---|---|
| 体力 | 初期値100。被害イベントで減る。 |
| 狂気 | 初期値0。25で視覚の乱れ、50で本文の対象文字の約2割が文字化け、80でクレヨン画調の現実逃避演出へ進む。 |
| ダイス | 1〜100の出目を10面ダイス2個で表示。目標値以下で成功。廊下は隠密65または回避55、深淵の間の逃走は回避50。 |
| 銀の鍵 | シナリオ開始時に2回。表示される場面で自由行動を入力できる。APIキーなしでもローカル判定が動く。キーを設定した場合はGeminiによる判定を試みる。 |
| 結末 | 生還「雨夜の脱出」、狂気同化「永遠のお花畑」、捕食「深淵の糧」、焼却生還「灰燼の夜明け」。 |

## 音響

| 場面 | v0.3.1の演出 |
|---|---|
| 玄関ホール | 雨を薄く流し、最初の本文で古びたドアを鳴らす。 |
| 暗い廊下 | 地下通路の環境音を敷き、右奥から引きずる音を鳴らす。 |
| 鉄扉 | 既存の1.2秒の間に追加の環境音を切り、直後に鉄扉の衝撃を鳴らす。 |
| 深淵の間 | 怪物が口を開く場面で触手の音を鳴らす。 |

心音、ダイス、既存BGMはゲーム内で生成する。追加素材は効果音ラボの6音（雨が降る1、古びたドアを開ける、地下通路、重いものを引きずる、鉄の扉を閉める、うごめく触手）。新規SEの読み込みに失敗した場合、一発音は既存の生成音に戻る。環境音は読み込めた場合に加わる。

## セーブと設定

同じブラウザの保存領域にオート1枠、手動3枠を保持する。v3を優先し、枠ごとに旧v2へフォールバックする。旧版の地下室のセーブは進行位置に応じて地下階段または深淵の間へ対応付ける。設定は全体・BGM・SEの音量、文字速度、任意のAPIキー。

## 開発方針

### 演出とシナリオ

- ホラー映画のように、音、画面、文章の間を合わせる。探索や会話で安心できる時間を作り、危険が去ったと思ったところで強烈な演出を入れる。現行の単調さは、静けさと衝撃の落差で改善する。
- 本編では複数の登場人物に動機と秘密を持たせ、その中に犯人や、ニャルラトホテプのように正体を隠した存在が紛れている章を設ける。証言や物証にトリックの手がかりを置き、真相が判明したときに、以前の場面の意味が変わるように伏線を回収する。
- 結末の規模は章ごとに変える。個人の生還から、世界の終焉に至る絶望的な結末まで扱う。

### 選択と分岐

プレイヤーは選択肢で行動を決め、判定が必要なときは自分でダイスを振る。その選択と出目が物語を動かしていると感じられるように、GM役のシステムやAIは、選択・出目・所持品・手がかりと整合する展開をつなぎ、用意されたエンディングのいずれかへ自然に導く。表示した判定条件と出目は分岐に反映する。

### ダイスを振らずに進む

場面ごとに、物語を直接進める行動、目に見える情報を確認する行動、技能判定を選べるようにする。振る前なら技能選択画面から元の選択肢に戻れる。判定後は、新しく分かった情報や起きた変化を反映した選択肢へ進む。

扉の例では「扉を開いて進む」「扉を調べる」「ダイスを振る」を表示する。「進む」はそのまま扉を開ける。「調べる」は錠や傷など、外から確認できる情報を得る。「ダイスを振る」では、たとえば聞き耳を選んでからスワイプする。

| 聞き耳の結果 | 展開例 |
|---|---|
| クリティカル | 内部の物音の位置や、奥へ遠ざかる間合いまで分かる。 |
| 成功 | 内側で何かを引きずる音が聞こえる。その情報を持って次の行動を選べる。 |
| 失敗 | 何も聞き取れない。中の様子は不明のまま次の行動を選べる。 |
| ファンブル | 耳を当てた拍子に半開きの扉が開き、室内へ倒れ込む。物音で中の存在に気づかれる。 |

施錠された扉など、同じ事故が起こり得ない場面では、その場に合うファンブルを設定する。

### 最優先の改修 — ダイスロール

1. **振る前に技能と条件を選ぶ**。画面左に、その場面で使える技能と技能値（隠密60、拳80、鍵開け90など）を表示する。技能をタップすると、その方法で何を試みるか、成功時の狙いと失敗時に起こり得るリスク、今回のクリティカル・成功・失敗・ファンブルの出目範囲が切り替わる。画面手前の10面ダイス2個はスワイプまで待機する。技能値は表示例。クリティカルとファンブルの具体的なしきい値は実装前に決める。
   - 判定条件を読んでいる間は、二連の心音を小さく鳴らし、対応端末では同じリズムで短く振動させる。スワイプで投げたとき、画面を閉じたとき、またはページを離れたときに止める。振動が使えない端末では心音と画面演出で緊張感を伝える。
2. **スワイプで投げる**。プレイヤーのスワイプを受けて初めてダイスが動く。方向と勢いを転がり方に反映し、画面端で跳ね返って減速、停止する。最初は画面内の反射・減速・回転を組み合わせ、スマホで手応えを確認する。厳密な3D衝突の再現は初回実装の要件から外す。
3. **停止後に結果を演出**。出目を見せて一拍置き、成功なら危機を抜けた安堵や手応えを、失敗なら迫る危険や代償を音と画面で伝える。クリティカルとファンブルには通常結果と区別できる強弱を付け、演出のあとで物語を進める。

#### 判定待ちの心音

| パターン | 心拍数 | 発動条件と鳴らし方 |
|---|---:|---|
| 平常 | 60 BPM | 序盤や危険の小さい判定。小さな二連音を約1秒おきに鳴らす。 |
| 切迫 | 165 BPM | 失敗が即死につながる判定。SANや体力が低くても、場面の致死性と組み合わせて切迫を判断する。詰まった二連音を約0.36秒おきに鳴らす。 |
| 狂気の陶酔 | 45 BPM | 終盤で現実を手放し、恐怖を快く感じる場面。即死の危険があっても切迫より優先し、丸く重い二連音を約1.33秒おきに鳴らす。 |

切迫の165 BPMは、高リスクの警察活動で記録された心拍を参考にする演出値。低SANや低体力だけで通常の探索が常に切迫になることは避け、陶酔はシナリオで明示する。対応端末の振動は心音の拍に合わせ、スワイプや画面離脱で止める。

参考資料 [Stress-Activity Mapping: Physiological Responses During General Duty Police Encounters](https://pmc.ncbi.nlm.nih.gov/articles/PMC6788355/)

#### 扉の判定例

| 技能 | 成功時 | 失敗時 |
|---|---|---|
| 隠密60 | 開いている扉をそっと開け、気づかれずに進む。 | 蝶番が鳴り、近くの神話生物が音を探り始める。 |
| 鍵開け90 | 錠の掛かった扉を静かに開ける。 | 錠が開かず、金具の音で警戒される。 |
| 拳80 | 扉を力ずくで開ける。開くが、衝撃音で神話生物が気づく。 | 扉が開かず、衝撃音で神話生物がこちらへ向かう。 |

選択した技能と判定結果で、扉が開いたか、どれだけ音が出たか、怪物が気づいたかを決め、続く本文・効果音・分岐に反映する。振る前は起こり得るリスクを提示し、実際に気づかれた結果は振ったあとに伝える。
